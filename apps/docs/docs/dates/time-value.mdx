## Usage

TimeValue shows `value` (`"HH:mm"` or `"HH:mm:ss"`) as `format` (`"24h"` by default, or `"12h"` with `amPmLabels`),
with seconds when `withSeconds` is set. A value that is not a time shows nothing. `timeValue(props)` returns the same
text as a string.

## Differences from Mantine

- `value` is a string; Mantine also takes a `Date`, which this port avoids (read the time out of it first).
- The text is wrapped in a `span`, where Mantine renders it bare.
