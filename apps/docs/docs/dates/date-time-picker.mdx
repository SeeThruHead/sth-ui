## Usage

DateTimePicker is an input that opens an [InlineDateTimePicker](/dates/inline-date-time-picker) in a Popover and shows
the value as `valueFormat` (`"DD/MM/YYYY HH:mm"`, with `:ss` when `withSeconds` is set). Enter in the time fields or
the submit button closes it. Closing drops a range that only has a start and clamps the value to `minDate` and
`maxDate`, as Mantine does. `clearable`, `name` (a hidden `YYYY-MM-DD HH:mm:ss` value), `readOnly`, `disabled` and
every Input prop work as on the other picker inputs.

Keep `DateTimePicker.init({ id, today, type, value }, context)` in the Model and route its Messages and Commands through
`update(model, message, context)`; it reports `Changed`, `Opened` and `Closed`.

## Differences from Mantine

- It is a submodel; the context goes to `init`, `update` and the view.
- `dropdownType="modal"` is not supported; the dropdown is always a Popover.
