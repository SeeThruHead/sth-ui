## Usage

YearPickerInput is a button-like input that opens a [YearPicker](/dates/year-picker) in a Popover. Keep
`PickerInput.init({ id, today, level: "year", type, value })` in the Model, route its Messages through
`PickerInput.update(model, message, options)` and its Commands back to the runtime, and render it with `model` and
`toParentMessage`. `update` reports `Changed` with the new value, and `Opened` and `Closed`. The value is shown as
`YYYY` by default; label, description, error, sections and the other Input props work as on TextInput.

## Differences from Mantine

- It is a submodel (`init`, `update`, out messages) rather than a controlled or uncontrolled component.
- `dropdownType="modal"` is not supported; the dropdown is always a Popover.
