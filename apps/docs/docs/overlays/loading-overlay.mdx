## Showing it

`visible` shows it at once, as Mantine does by default (its transition is 0ms). For a fade, hold a
`Transition.Model` and pass it as `model` with `transitionProps: { duration: 150 }`; it then follows
`Transition.mounted` like a Modal.

## Options

`loaderProps` go to the Loader (type, size, colour, label), `overlayProps` to the Overlay (colour, opacity,
blur, radius), and `zIndex` sets both layers (default the theme's overlay layer, 400). The layer is white in
light mode and dark-5 in dark mode at 75%, one `light-dark()` colour where Mantine renders two overlays. Parts:
`root`, `loader` and `overlay`.
