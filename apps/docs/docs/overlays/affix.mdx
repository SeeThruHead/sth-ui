## Usage

Affix fixes its children to a corner of the screen, inside a [Portal](/miscellaneous/portal). `position` takes
`top`, `left`, `bottom` and `right` as spacing values or pixels (bottom right, 0 and 0, by default), `zIndex` is 200
by default, and `withinPortal: false` keeps it where it is written.

## Differences from Mantine

- Mantine's demo shows the button only once the page scrolls; the example frame here does not scroll, so it is always
  shown.
