## Usage

FloatingIndicator highlights the active element in a group, for custom segmented controls, tabs and the like. It sits
over its target with CSS anchor positioning: give the active element `floatingIndicatorTarget(anchor)` in its styles,
render `FloatingIndicator` with the same `anchor` inside a parent with `position: relative`, and it moves (over
`transitionDuration`, 150ms by default) whenever the target changes. `target: false` hides it. It has no look of its
own: style it with the Styles API.

## Differences from Mantine

- Mantine measures the `target` and `parent` elements in JavaScript; here CSS anchor positioning places the indicator,
  so it follows its target with no measuring, and the target is named by `anchor` rather than passed as an element.
- The Tabs example needs Tabs to accept a custom indicator, which is not ported yet.
