## Element and data attributes

`component` picks the element (`section`, `nav`, `a`...). `mod` adds data attributes: `mod={{ active: true, step:
2 }}` gives `data-active` and `data-step="2"`.

## Hide or show by width

`hiddenFrom="sm"` hides it from the `sm` breakpoint up; `visibleFrom="sm"` shows it only from there.
