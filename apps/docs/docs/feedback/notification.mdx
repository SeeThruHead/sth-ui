## Usage

Notification shows a message with an optional `title`, a coloured bar on the left and a close button. `onClose` is the
message the close button sends. `color`, `radius`, `withBorder` and `withCloseButton` change how it looks, and
`loading` shows a loader in place of the bar or icon.

## Accessibility

The root has `role="alert"` unless you give another `role`. The close button is named by `closeButtonLabel` ("Close
notification" by default).

## Styles API

Its parts are `root`, `icon`, `loader`, `body`, `title`, `description` and `closeButton`. The root carries
`data-with-icon` and `data-with-border`, and the description `data-with-title`.
