## Usage

Alert shows an important message: a `title`, an optional `icon` and the message as `children`. `variant` is `light`
(default), `filled`, `outline`, `default`, `transparent` or `white`; `color` and `radius` style it, and
`autoContrast` picks black or white text for a filled alert.

## Accessibility

- The root has `role="alert"` (change it with `role`).
- With an `id`, the alert is labelled by its title (`aria-labelledby`) and described by its message
  (`aria-describedby`).
- Set `closeButtonLabel` so the close button has a name.

## Differences from Mantine

- Mantine makes its own id for the ARIA links; here pass `id` to get them.
