## Size and colour

`size` is `xs` to `xl`, a number of pixels or any CSS size; `color` is a theme colour, a shade or any CSS
colour.

<Example story="feedback-loader--sizes-and-colors" caption="xs, xl in red, and 50px dots in a custom colour" />

## Custom loaders

`loaders` adds your own types, or replaces a built-in one, and `type` picks one. Set it once as a default and
every Loader (and every Button's `loading` state) can use it:

```ts
const line: LoaderView = (h, root) => h.span(root(styles.line), [])

createUi({ components: { Loader: { defaultProps: { loaders: { line }, type: "line" } } } })
```

`root(shape)` gives the loader's own attributes with your style added, so size, colour and the accessible
name still apply. An unknown `type` falls back to `oval`.

<Example story="feedback-loader--custom-loaders" caption="A custom line, a replaced oval and an unknown type" />

`children` replaces the shape entirely with your own content.
