## Usage

`data` is a list of `{ name, value, color }` segments. Each fills its share of a `rows` by `columns` grid (10 by 10),
rounded so the counts add up (largest remainder); negative and non-finite values count as zero. A legend sits below,
and hovering one of its items fades the other segments. The grid is an image named by a summary of the data.

## Total, direction, size and tooltip

- `total` leaves cells empty for the part of a larger whole the data does not cover.
- `fillDirection` fills `left-to-right` (default), `right-to-left`, `top-to-bottom` or `bottom-to-top`.
- `size` sets the grid's width, gaps included (the gap shrinks when it alone would be too wide); otherwise cells are
  20px.
- `gap`, `cellRadius` and `emptyColor` style the cells.
- `legendPosition` puts the legend `top`, `bottom`, `left` or `right`, and `withLegend: false` hides it.
- `withTooltip` shows the segment's name, or `getTooltipLabel({ ...segment, count })`, above the pointer.
- `ariaLabel` names the whole chart as a group.
