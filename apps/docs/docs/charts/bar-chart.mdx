## Usage

BarChart takes the same data, axes, grid, legend and tooltip props as [LineChart](/charts/line-chart). Each category
gets a band; its bars fill the middle 80% of the band with 4px between them. Hovering a band fills it with
`cursorFill` and shows a tooltip.

<Configurator story="charts-barchart--configurator" />

## Stacked, percent and bar width

`type: "stacked"` stacks the series in one bar per category, and `type: "percent"` stacks them to 100% with the y
axis in percent. `maxBarWidth` caps each bar's width, `fillOpacity` sets the bars' opacity, and negative values
hang down from zero.

## Differences from Mantine

- Bars are HTML elements over the grid rather than recharts shapes; `barProps`, `barChartProps`, `getBarColor` and
  children are not supported.
- Not ported yet: the `waterfall` type, `orientation: "vertical"`, value labels on bars, `minBarSize`, a right y axis
  and reference areas.
