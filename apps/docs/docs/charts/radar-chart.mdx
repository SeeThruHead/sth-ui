## Usage

`data` is a list of rows, one per axis, `dataKey` the row field that names the axis, and `series` the fields drawn
as polygons, each `{ name, color, strokeColor?, opacity?, label? }` (opacity 0.4 by default). The first axis points
up and the rest follow clockwise. Give the chart a height with `h`.

<Configurator story="charts-radarchart--configurator" />

## Multiple series, legend, tooltip and dots

- `withLegend` adds a legend below; hovering one of its series fades the others.
- `withTooltip` shows every series' value on the axis nearest the pointer.
- `withDots` marks each value.
- `withPolarGrid`, `withPolarAngleAxis` (on) and `withPolarRadiusAxis` (off) toggle the grid and the labels.
- `gridColor` and `textColor` colour them.

## Differences from Mantine

- It draws its own SVG rather than recharts, in a 300 by 300 square scaled to fit, so its labels are 12px at a height
  of 300; `radarProps`, `polarGridProps`, the axis props and children are not supported.
