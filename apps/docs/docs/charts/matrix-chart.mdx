## Usage

`data` is a list of `{ x, y, value }` cells. Columns and rows follow the order the `x` and `y` values first appear
(or `xLabels` and `yLabels`), and each cell is coloured by its value against the domain (the finite values' range, or
`domain`) in four shades of green; missing values are gray. `withXLabels` and `withYLabels` name the columns and rows.
The chart is an image described by its size and range.

## Labels, legend, tooltip and colours

- `xLabelsRotation` (-90) turns the column labels, and `xLabelsPosition` puts them `bottom` or `top`.
- `withLegend` adds a Less to More scale below (`legendLabels`).
- `withTooltip` with `getTooltipLabel(cell)` shows a label above the pointer.
- `colors`, `emptyColor`, `cellSize`, `gap`, `cellRadius` and `fontSize` style the cells.
- `ariaLabel` names the chart instead of the generated description.

## Differences from Mantine

- `getTooltipLabel` returns a string, and `getCellProps` and `tooltipProps` are not supported.
