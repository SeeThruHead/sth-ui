## Disclaimer

`Input` is the base for the other inputs (TextInput, Textarea, Select and the rest). Reach for it to build a
custom input; for a plain text field use `TextInput` once it is built.

## Usage

`Input` renders the field itself, with Mantine's `variant` (`default`, `filled`, `unstyled`), `size` (`xs` to
`xl`), `radius`, `disabled`, and `error` and `success` styles. Bind it like any Foldkit field: `value` from your
model, `onInput` (or `onChange`) to a message.

## Loading state

`loading` shows a loader in the right section, or the left one with `loadingPosition: "left"`.

## Left and right sections

`leftSection` and `rightSection` sit inside the field; `leftSectionWidth` and `rightSectionWidth` size them, and
`leftSectionPointerEvents` and `rightSectionPointerEvents` (default `none`) let them take clicks.

<Example story="inputs-input--sections" caption="An icon, and a clear button that empties the field" />

## Change input element

`component` is `input` (default), `textarea`, `select` or `button`. Set `pointer` for a pointer cursor, and
`multiline` with `textarea`.

## Input.Wrapper component

`InputWrapper` adds the label, description and error around a field. Give it an `id`, and build the field in
`input`, spreading the `wiring` it hands you: that sets the field's `id`, links the label to it, and fills
`aria-describedby` with the description and error, as Mantine does through context.

## required and withAsterisk props

`required` on the wrapper shows a red asterisk after the label; on the field it sets the `required` attribute.
`withAsterisk` shows or hides the asterisk on its own.

## error prop

`error: true` styles the field and sets `aria-invalid`; text shows it under the field as well.
`withErrorStyles: false` keeps the message but leaves the field unstyled.

## Accessibility

With a wrapper, the label names the field and the description and error describe it. Without one, give the field
an accessible name (`attributes: { input: { "aria-label": "..." } }`). Set `withAria: false` only when you wire
the attributes yourself.
