## Usage

Checkbox is built on `@foldkit/ui`'s accessible checkbox: a `role="checkbox"` button named by its label, with
`aria-checked` saying whether it is checked. Keep `checked` in your model and update it from `onChange`, which gets
the new value. `id` is required; it names the label, description and error.

<Configurator story="inputs-checkbox--configurator" />

## Controlled state

Checkbox is always controlled: `checked` is what it shows and `onChange(checked)` is the message it sends.

## Read only

`readOnly` keeps the checkbox as it is and marks it `aria-readonly`; clicks and Space do nothing.

## Checkbox with uncontrolled forms

Give it a `name` (and `value`, `"on"` by default) and it renders a hidden input, so a submitted form sends the value
while it is checked.

## Checkbox.Group

`CheckboxGroup` keeps one list of checked values for several checkboxes, inside an Input.Wrapper (label,
description, error, withAsterisk). `children` gets a `checkbox(value, props)` function that builds a checkbox
wired to the group; lay them out however you like.

## Checkbox.Indicator

`ui.CheckboxIndicator` looks like a checkbox but is only a picture of one: no input, no label, no handlers. It takes
`checked`, `indeterminate`, `disabled`, `size`, `radius`, `color`, `iconColor`, `variant` and `autoContrast`. Use it
inside custom controls.

## Checkbox.Card

`ui.CheckboxCard` is a button with `role="checkbox"` that toggles `checked` through `onChange`; `withBorder` (on) and
`radius` style it. Its `children` can be a function of the card's state (`checked` and `indeterminate`), which is how
an indicator inside follows the card:

## Accessibility

The label names the checkbox (`aria-labelledby`), the description and error describe it (`aria-describedby`), and an
error sets `aria-invalid`. A group has `role="group"` named by its label. Space toggles a focused checkbox, and a
click on its label toggles it too.

## Differences from Mantine

- The control is a `button` with `role="checkbox"` from `@foldkit/ui`, not a native `input`; part `input` styles it.
- `onChange` gets the new checked state instead of an event; there is no `defaultChecked`.
- A group's children are built by a function instead of reading a React context.
- `Checkbox.Indicator` and `Checkbox.Card` are not ported yet.
