## Usage

`NumberInput` is a [TextInput](/inputs/text-input) for numbers: every Input and wrapper prop, a `decimal` keyboard on
phones, increment and decrement controls, and Arrow Up and Arrow Down to step.

<Configurator story="inputs-numberinput--configurator" />

## Controlled

Keep the value in your model and update it from `onChange`. The value is `number | string`: a number when what was
typed is a complete number, and the text as typed otherwise (`""`, `"-"`, `"12."`), so half-typed numbers are kept
as they are.

## Value type

`onChange` gets a `number` for complete numbers and a `string` for anything else; check with `typeof` before doing
arithmetic.

## min and max

`min` and `max` limit the value: the controls stop at them, and the value is clamped when the field is committed
(on blur, Mantine's `clampBehavior: "blur"`).

## Clamp behavior

`clampBehavior: "strict"` clamps while typing; `"none"` never clamps.

## Grouping, leading zeros, isAllowed, hold to step and custom controls

`thousandsGroupStyle` groups by `thousand` (default), `lakh` (`12,34,567`), `wan` (`123,4567`) or `none`.
`allowLeadingZeros={false}` drops zeros as you type, and `trimLeadingZeroesOnBlur={false}` keeps them after blur.
`isAllowed` gets `{ value, floatValue }` for what a key would make and refuses the key when it returns false.
`selectAllOnFocus` selects the text when the field gets focus. With `stepHoldDelay` and `stepHoldInterval`, holding a
control keeps stepping. `stepNumber` builds your own controls, as Mantine's `handlersRef` does.

## Differences from Mantine

- Formatting is built in rather than from `react-number-format`: prefix, suffix, thousands grouping, decimal scale and
  separator, negative and decimal limits. Bigint values are not ported.
- `onValueChange`, `onMinReached` and `onMaxReached` are not separate callbacks: `onChange` returns your one message,
  and your update can compare the value with `min` and `max`.
- `handlersRef` is `stepNumber(value, direction, { step, min, max })`, which your own buttons call.
- Keys that would be refused (a minus, a separator, extra decimals) are stopped before they reach the field.
