## Usage

`TextInput` is an [Input](/inputs/input) inside an Input.Wrapper: every Input prop (variant, size, radius,
sections, loading, error, success, disabled) and every wrapper prop (label, description, error, required,
withAsterisk, inputWrapperOrder) in one component. Give it an `id`; it links the label, description and error to
the field.

## Styles API

TextInput's parts are the wrapper's (`root`, `label`, `required`, `description`, `error`, `success`) and the
input's (`wrapper`, `input`, `section`). Style props such as `mt` apply to `root`. Defaults and styles set for
`TextInput` in `createUi` apply on top of those for `Input` and `InputWrapper`, as in Mantine.

<Example story="inputs-textinput--styles-api" caption="A purple label, a dashed input and an italic description" />

## Accessibility

With `label` the field is named by it; `description`, `error` and `success` describe it through
`aria-describedby`, and `error` sets `aria-invalid`. Without a label, give the field a name with
`attributes: { input: { "aria-label": "..." } }`.
