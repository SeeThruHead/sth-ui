## Usage

MaskInput formats what is typed into `mask`: tokens take characters, literals are inserted for you, and the caret
skips over them. It accepts every [Input](/inputs/input) prop. Hold `MaskInput.init({ id })` in your model and route
its messages; `update` returns `ChangedRaw` (the raw and masked values) and `Completed` (when every required slot is
filled) as out messages, and the model keeps `raw`, `masked` and `complete`.

## Mask pattern syntax

Each character of the mask is a **token** (a slot to type into) or a **literal** (inserted automatically).

### Built-in tokens

- `9`: a digit (`[0-9]`)
- `a`: a letter (`[A-Za-z]`)
- `A`: an uppercase letter (`[A-Z]`)
- `*`: a letter or digit (`[A-Za-z0-9]`)
- `#`: a digit or sign (`[-+0-9]`)

### Optional segments

`?` marks every slot after it optional, so the value is complete without them. `alwaysShowMask` keeps the slots
visible when the field is empty, `showMaskOnFocus: false` hides them on focus, and `autoClear` empties an incomplete
value on blur.

### Escaping

Put `\` before a token character to make it a literal: `"\\A999"` starts with a fixed `A`.

## Utilities

`formatMask(raw, options)`, `unformatMask(masked, options)`, `isMaskComplete(masked, options)` and
`generatePattern("full" | "full-inexact", options)` from `hooks/mask.ts` work without the input.

## Differences from Mantine

- The reset ref is a `Reset` message, and `onChangeRaw` / `onComplete` are the `ChangedRaw` and `Completed` out messages.
- `beforeMaskedStateChange` is left out: Mantine declares it but never calls it.
