## Usage

Breadcrumbs puts `separator` (`/` by default) between its `children`, with `separatorMargin` (`xs`) on each side. A
child can be any content, wrapped in a `breadcrumb` div, or a function that receives the breadcrumb part to spread into
its own root, as Mantine clones its element children:

```ts
ui.Breadcrumbs(h, {
  children: links.map(
    ({ title, href }) =>
      (crumb: BreadcrumbBinding) =>
        ui.Anchor(h, { ...crumb, href, children: [title] })
  )
})
```
