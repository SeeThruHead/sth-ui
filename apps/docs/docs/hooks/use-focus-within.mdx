## Usage

The `focusWithin()` Mount sends `FocusChanged` with `true` when focus moves into the element and `false` when it
leaves it; moving between elements inside it sends nothing.

<Example height={220} story="hooks-usefocuswithin--usage" caption="useFocusWithin" />

## Differences from Mantine

- It is a Mount sending a Message rather than a hook with `onFocus` and `onBlur` callbacks.
