## Usage

The `scrollSpy({ selector, offset, scrollHost })` Mount reads the headings matching `selector` (`h1` to `h6`) and sends
`Scanned` with their text, ids and depths, then `Scrolled` with the index of the heading in view as the page (or the
`scrollHost` element) scrolls. It is what [TableOfContents](/navigation/table-of-contents) is built on.

## Differences from Mantine

- It is a Mount sending Messages rather than a hook; `getDepth` and `getValue` are fixed to the heading level and its text.
