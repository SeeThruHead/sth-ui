## Usage

The `mutationObserver({ childList, subtree, attributes, characterData })` Mount observes the element it is on and sends
`Mutated` with the type of each change in a batch.

<Example height={200} story="hooks-usemutationobserver--usage" caption="useMutationObserver" />

## Differences from Mantine

- It is a Mount sending the mutation types rather than a ref with a callback receiving the records; for `useMutationObserverTarget`, put the Mount on the target element.
