## Usage

`documentVisibility` is a Stream of `document.visibilityState` (`visible` or `hidden`), starting with the current state
and sending it again on each `visibilitychange`. Return it from a Subscription.

<Example height={80} story="hooks-usedocumentvisibility--usage" caption="useDocumentVisibility" />

## Differences from Mantine

- It is a Stream for a Subscription rather than a hook.
