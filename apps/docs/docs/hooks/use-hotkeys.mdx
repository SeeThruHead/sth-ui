## Usage

`hotkeys(items, { tagsToIgnore, triggerOnContentEditable })` is a Stream of the hotkeys pressed anywhere on the page,
each item `[hotkey, { preventDefault, usePhysicalKeys }]`. Hotkeys read as Mantine's: `mod+K` is Ctrl or Cmd with K,
modifiers must match exactly, and `[plus]` is the plus key. Keys typed in `INPUT`, `TEXTAREA` and `SELECT` are
ignored by default, as is content editable text unless `triggerOnContentEditable`. For one element (Mantine's
`getHotkeyHandler`), put the `hotkeyHandler(hotkeys, options)` Mount on it; it does not ignore any tags.

## Differences from Mantine

- `hotkeys` is a Stream of the matching hotkey strings and `hotkeyHandler` a Mount sending `HotkeyPressed`, rather than handlers.
