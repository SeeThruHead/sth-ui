## Usage

`eyeDropperSupported()` says whether the browser has the EyeDropper API (and is not Opera, as Mantine checks).
`openEyeDropper({})` is a Command that opens it and sends `Picked` with the color, or `Failed` when the user cancels or
the API is missing.

## Differences from Mantine

- `open` is a Command sending `Picked` or `Failed` rather than a promise; `supported` is a function to call when building the Model.
