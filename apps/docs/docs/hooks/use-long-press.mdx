## Usage

The `longPress({ threshold, events, cancelOnMove })` Mount sends `Pressed` with each stage: `started` on press,
`longPressed` once it is held for `threshold` (400ms), `finished` when a long press is released, and `cancelled` when
a press is released early. `events` chooses mouse, touch or both, and `cancelOnMove` (`true` for 10px, or a distance)
cancels the press when the pointer moves that far.

## Differences from Mantine

- It is a Mount sending stages rather than a hook returning event handlers with callbacks.
