## Usage

`fullscreen` is a Stream of whether something on the page is fullscreen, starting with the current state and sending it
on every `fullscreenchange` and `fullscreenerror`. `toggleFullscreen({ selector })` is a Command that makes the first
element matching the selector fullscreen (`"html"` for the whole page), or leaves fullscreen when something already
is; it sends `Failed` with the browser's error when the request is refused.

## Differences from Mantine

- Mantine's `useFullscreen` and `useFullscreenElement` become one Stream and one Command, chosen by selector.
- Only the standard API is used; the `webkit`, `moz` and `ms` fallbacks are for browsers this library does not target.
