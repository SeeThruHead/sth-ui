## Usage

`validated(initial, validate, initialValid?)` makes `{ value, lastValidValue, valid }` to keep in the Model, and
`changeValidated(state, value, validate)` gives the next one: `value` is always the latest, `valid` says whether it
passed, and `lastValidValue` holds the most recent value that did (`Option.none()` until one has). `initialValid`
overrides the first validity, as Mantine's `initialValidationState` does.

## Differences from Mantine

- These are pure functions over a Model value rather than a hook; the Message that carries the change calls
  `changeValidated` in `update`.
- `lastValidValue` is an `Option` instead of `undefined`.
