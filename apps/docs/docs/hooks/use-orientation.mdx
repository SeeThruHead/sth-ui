## Usage

`orientation` is a Stream of `{ angle, type }` from `screen.orientation`, starting with the current orientation and
sending each change. Return it from a Subscription.

<Example height={90} story="hooks-useorientation--usage" caption="This screen's orientation" />

## Differences from Mantine

- It is a Stream for a Subscription rather than a hook; the Model's own initial value replaces `defaultAngle` and
  `defaultType`.
