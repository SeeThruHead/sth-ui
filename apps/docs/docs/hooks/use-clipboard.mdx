## Usage

`copyText({ text })` is a Command that writes to the clipboard and sends `Copied` or `CopyFailed` with the error.
`expireCopy({ generation, timeout })` sends `CopyExpired` after the timeout (Mantine's is 2000ms). The state functions
in `clipboard.ts` (`copied`, `copyFailed`, `expired`, `resetClipboard`) keep `{ copied, error, generation }`, so only
the latest copy's timer clears `copied`.

## Differences from Mantine

- It is a pair of Commands and pure state functions rather than a hook; the error is a string in an `Option`.
