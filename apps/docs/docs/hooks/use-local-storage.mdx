## Usage

`storedValue(kind, key)` is a Stream of the raw stored string (`kind` is `localStorage` or `sessionStorage`), sent at
the start, when another tab changes it, and after every write in this tab. `writeStorage({ kind, key, value })` stores
the value as JSON and `removeStorage({ kind, key })` deletes it; a blocked storage sends `Failed`. `readStored(area,
key, decode, fallback)` and `readJson(text)` read a stored value back as Mantine does (JSON, else the raw text), checked
by a Schema decoder.

## Differences from Mantine

- Reading is a Stream and writing a Command, rather than a hook returning a setter; the value is checked with a Schema instead of `deserialize`.
- `sync` is a choice of whether to subscribe at all.
