## Usage

`stateHistory(initial)` makes `{ history, current }`. `setHistory(state, value)` adds a value after the current one
and drops anything ahead of it, `backHistory(state, steps = 1)` and `forwardHistory(state, steps = 1)` move through
the history without going past either end, and `currentOf(state)` is the current value. Reset by starting again with
`stateHistory(initial)`.
