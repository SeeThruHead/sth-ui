## Usage

`windowScroll` is a Stream of `{ x, y }`, sent at the start and on each `scroll` and `resize`. `scrollWindow({ x, y })`
is a Command that scrolls smoothly to the given axes; either can be left out.

<Example height={90} story="hooks-usewindowscroll--usage" caption="useWindowScroll" />

## Differences from Mantine

- Reading and scrolling are a Stream and a Command rather than a hook returning both.
