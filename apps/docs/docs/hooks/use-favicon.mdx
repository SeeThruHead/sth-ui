## Usage

`setFavicon({ url })` is a Command that replaces the page's icon links with one of its own the first time, then
points it at `url`, with the type read from the extension (`ico`, `png`, `svg`, `gif`; no type otherwise).

<Example height={100} story="hooks-usefavicon--usage" caption="useFavicon" />

## Differences from Mantine

- It is a Command run when the icon changes rather than a hook that follows a value.
