## Usage

`setDocumentTitle({ title })` is a Command that sets `document.title` to the trimmed title, and does nothing for a
blank one, as Mantine does. Run it from `update` whenever the title should change.

<Example height={90} story="hooks-usedocumenttitle--usage" caption="useDocumentTitle" />

## Differences from Mantine

- It is a Command run when the title changes rather than a hook that follows a value.
