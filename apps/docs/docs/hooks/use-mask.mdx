## Usage

`formatMask(raw, options)` fits raw characters into a mask such as `"(999) 999-9999"` (`9` a digit, `a` a letter, `*`
either, with custom `tokens`, `slotChar`, `alwaysShowMask` and the rest of Mantine's options), `unformatMask` reads
the raw characters back, `isMaskComplete` says whether every slot is filled, and `generatePattern` builds an input
`pattern`. The cursor and keyboard handling live in [MaskInput](/inputs/mask-input), which is built on them.

## Differences from Mantine

- The formatting is pure functions; the editing behaviour Mantine's hook attaches to an input is MaskInput's.
