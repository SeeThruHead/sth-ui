## Usage

The `intersection({ rootMargin, threshold })` Mount sends `Intersected` with `isIntersecting` and
`intersectionRatio` for the latest entry each time the element crosses a threshold. `useInViewport` is the same Mount,
keeping only `isIntersecting`.

<Example height={140} story="hooks-useintersection--usage" caption="useIntersection and useInViewport" />

## Differences from Mantine

- It is a Mount sending the entry's two values rather than the entry itself, which cannot be kept in a Model; the root is the viewport.
