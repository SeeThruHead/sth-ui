## Usage

`textSelection` is a Stream of the selected text, starting with the current selection and sending it on every
`selectionchange`.

<Example height={110} story="hooks-usetextselection--usage" caption="useTextSelection" />

## Differences from Mantine

- It sends the selected text rather than the live `Selection` object, which cannot be kept in a Model.
