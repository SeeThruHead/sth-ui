## Name it

The icon has no text, so give every CloseButton a `label` (its accessible name), as Mantine's examples pass
`aria-label`.

## Options

`size` is `xs` to `xl` (default `md`, 28px) or pixels; `iconSize` sizes the × (default 70%); `radius`;
`variant` is `subtle` (a hover background, the default) or `transparent`. `icon` replaces the ×, `children`
follow it, and `disabled` dims it.
