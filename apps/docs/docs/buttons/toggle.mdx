## Usage

Toggle is a button that is pressed or not. Give an icon-only toggle an `ariaLabel`.

<Configurator story="buttons-toggle--configurator" />

## Controlled

`active` is the state and `onActiveChange` turns the new state into a message; the model keeps it.

```ts
ui.Toggle(h, {
  ariaLabel: "Bold",
  active: model.bold,
  onActiveChange: (active) => Message.Toggled({ format: "bold", active }),
  children: [TextBIcon(h, { weight: "bold", size: "100%" })]
})
```

## Variants, sizes and colors

An active toggle uses `variant` (`filled` by default, or `light`, `outline`, `subtle`, `transparent`, `default`,
`white`) with `color`. `size` is `xs` to `xl` or any size, and `radius` rounds it.

## Accessibility

Toggle renders a `button` with `aria-pressed` that follows `active`. `disabled` sets `disabled` and `aria-disabled`,
takes it out of the tab order and ignores clicks.

## Styles API

Its only part is `root`, carrying `data-active`, `data-disabled`, `data-auto-width` and `data-variant`.

## Differences from Mantine

- Toggle is controlled only: there is no `defaultActive`, since the state lives in the model.
