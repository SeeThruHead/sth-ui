## Any element

`component` renders it as `a` (with `href`), `div` or `span`. A `div` or `span` gets `role="button"` and a tab
stop so it still works from the keyboard; `disabled` on them sets `aria-disabled` and removes the tab stop.
`label` gives it an accessible name when its content is only an icon.

## Styles API

One part, `root`. Like every component it takes style props (`p`, `bd`, `bdrs`...), `mod` for data attributes,
`styles`, `attributes` and `unstyled`.
