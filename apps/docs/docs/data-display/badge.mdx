## Usage

`variant` is `filled` (the default), `light`, `outline`, `dot`, `transparent`, `white`, `default` or
`gradient`; `color` takes any palette colour, a shade such as `red.7`, or any CSS colour.

<Configurator story="data-display-badge--configurator" />

<Example story="data-display-badge--variants" caption="Every variant" />

## Gradient

`variant="gradient"` reads `gradient`: `from`, `to` and `deg`.

<Example story="data-display-badge--gradient" caption="Blue to cyan at 90 degrees" />

## Size and radius

`size` is `xs` to `xl` (default `md`, 20px tall) or a CSS length; `radius` defaults to fully round.

## autoContrast

With `autoContrast`, a `filled` badge picks black or white text for its colour, so a light colour stays
readable. It works for palette colours today; shades and custom colours follow with su-j00m.

<Example story="data-display-badge--auto-contrast" caption="Lime, without and with autoContrast" />

## Styles API

Badge's parts are `root`, `section` and `label`; each takes a StyleX style in `styles` and attributes in
`attributes`. See the Styles API tab for its variables and data attributes.

<Example story="data-display-badge--styles-api" caption="Taller, not uppercase, an italic label and red sections" />
