## Usage

OverflowList shows as many `data` items as fit, each drawn by `renderItem`, and puts the rest behind
`renderOverflow(items)`. It measures itself, so it keeps a small model: hold `OverflowList.init()` in yours, route its
messages through `toParentMessage` and update it with `OverflowList.update`. Drag the corner to resize:

<Example height={100} story="data-display-overflowlist--usage" caption="Fruit badges" />

## Data type

`data` can hold any type; `renderItem` and `renderOverflow` receive it. `getItemKey` tells the list when items were
reordered, so it measures again (strings and numbers are compared by value already).

## Max rows

`maxRows` (1 by default) lets the items wrap onto more rows:

## Styles API

Its only part is `root`; `gap` sets the space between items (`xs` by default).

## Differences from Mantine

- The list keeps its measurements in a model you hold, as every stateful component here does.
