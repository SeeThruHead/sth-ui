## Usage

Mark renders a `<mark>` element with black text on a highlight colour, yellow by default.

<Configurator story="typography-mark--configurator" />

## Color

`color` takes a theme colour name, a shade like `red.4`, or any CSS colour. A theme colour name uses its shade 2 in
the light scheme and shade 5 in the dark scheme; a shade or a CSS colour is used in both.
