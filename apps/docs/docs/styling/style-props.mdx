# Style props

Every component takes Mantine's style props on its root: `m`, `mt`, `p`, `px`, `w`, `maw`, `h`, `c`, `bg`, `bd`,
`bdrs`, `ff`, `fz`, `fw`, `lh`, `ta`, `tt`, `pos`, `display`, `flex` and the rest. Theme sizes (`m="md"`), negative
spacing (`mt="-sm"`), palette colours (`c="grape"`, `bg="grape.1"`) and plain CSS values all work.

## Responsive values

Give an object to change a value by breakpoint: `p={{ base: "xs", sm: "xl" }}`. Each breakpoint keeps the last
value set below it. `bd` and `bg` take plain values only.
