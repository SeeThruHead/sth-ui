## Usage

`Field.init({ initialValue })` keeps one value outside a form. Route its Messages through
`Field.update(model, message, context)` and wire an input with `fieldProps` or `textFieldProps`. `validate` takes the
value and returns an error, nothing, or an Effect of either; `validateOnChange`, `validateOnBlur` and
`clearErrorOnChange` (true) choose when it runs. `update` reports `ValueChanged`.

## Status

`model.error`, `model.touched` and `model.validating` hold the field's state; `isDirty(model)` compares the value with
the initial one. `RequestedValidation`, `SetError`, `Reset` and `ResetTouched` change them.

## Differences from Mantine

- The field is a submodel driven by Messages, with no uncontrolled mode or `key`.
- Async validation returns an Effect, and a newer validation replaces one still running.
