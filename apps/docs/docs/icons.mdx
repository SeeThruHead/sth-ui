# Icons

`@sth-ui/icons` has every [Phosphor](https://phosphoricons.com) icon, the set Mantine's own examples use, as a
Foldkit view. Import each icon from its own module, so an app only ships the icons it uses:

```ts
import { HouseIcon } from "@sth-ui/icons/icons/HouseIcon.ts"

ui.Button(h, { leftSection: HouseIcon(h, { size: 16 }), children: ["Home"] })
```

## Weights

`weight` is `thin`, `light`, `regular` (the default), `bold`, `fill` or `duotone`.

<Example story="guides-icons--weights" caption="One icon in every weight" />

## Size, colour and names

`size` takes pixels or any CSS length and defaults to `1em`, so an icon matches the text around it. `color`
defaults to `currentColor`, so it follows the text colour. An icon is hidden from screen readers unless it has
a `label`, which makes it an image with that name; give one to every icon that carries meaning on its own, such
as the only content of a button. `mirrored` flips it for right-to-left layouts.
